# TextUtils

TextUtils is a word counter and a character counting utility which can be used to manipulate your text in the way you want.

## Features

- _Text Transformation Suite:_

  - _Uppercase Conversion:_ Converts all characters in your text to their uppercase equivalents, useful for titles or emphasis.
  - _Lowercase Conversion:_ Transforms all characters to their lowercase form, ideal for standardizing text.
  - _Capitalize First Letter (Coming Soon):_ Automatically capitalizes the first letter of each word.

- _Real-time Analytics:_

  - _Word Count:_ Dynamically updates the number of words as you type or paste.
  - _Character Count:_ Provides an accurate count of all characters (including spaces) for strict limits.
  - _Read Time Estimation:_ Calculates an approximate time it would take to read the current text.

- _Text Cleanup Tools:_
  - _Remove Extra Spaces:_ Eliminates multiple spaces between words, reducing double spaces to single spaces for cleaner text.
  - _Clear Text:_ Resets the entire text area, ready for new input.
